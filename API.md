# Rock Paper Scissors Battle API

Base URL when running locally:

```text
http://localhost:8080/api
```

All request and response bodies are JSON. Send `Content-Type: application/json` for `POST` requests.

## Common Types

### Item

Valid item values are:

```json
["rock", "paper", "scissors"]
```

Item input is trimmed and lowercased before validation. For example, `" Rock "` is stored as `"rock"`.

### GameSessionResponse

```json
{
  "id": "4d93c354-d7c5-43cf-9be2-b7756117d4f2",
  "playerChoice": "rock",
  "status": "started",
  "winner": null,
  "initialRockCount": 10,
  "initialPaperCount": 10,
  "initialScissorsCount": 10,
  "finalRockCount": null,
  "finalPaperCount": null,
  "finalScissorsCount": null,
  "transformations": null,
  "durationMs": null,
  "createdAt": "2026-06-11T12:15:30.123456+03:00",
  "completedAt": null
}
```

Fields:

| Field | Type | Notes |
| --- | --- | --- |
| `id` | string | UUID session id. |
| `playerChoice` | string | Normalized item chosen by the player. |
| `status` | string | Currently `started` or `completed`. |
| `winner` | string or null | Winning item after completion. |
| `initialRockCount` | integer | Always `10` for new sessions. |
| `initialPaperCount` | integer | Always `10` for new sessions. |
| `initialScissorsCount` | integer | Always `10` for new sessions. |
| `finalRockCount` | integer or null | Set when the session is completed. |
| `finalPaperCount` | integer or null | Set when the session is completed. |
| `finalScissorsCount` | integer or null | Set when the session is completed. |
| `transformations` | integer or null | Number of item transformations during the battle. |
| `durationMs` | integer or null | Battle duration in milliseconds. |
| `createdAt` | string | Timestamp generated by PostgreSQL. |
| `completedAt` | string or null | Timestamp generated by PostgreSQL on completion. |

### ErrorResponse

Validation and not-found errors use this shape:

```json
{
  "error": "Item must be one of: rock, paper, scissors."
}
```

Unexpected server errors use:

```json
{
  "error": "Unexpected server error."
}
```

## Endpoints

## GET /health

Checks whether the API is running and whether the database responds to `SELECT 1`.

### Request

No request body.

### Response 200

```json
{
  "status": "ok",
  "database": "ok"
}
```

If the API is running but the database ping fails, `database` is `"unavailable"`:

```json
{
  "status": "ok",
  "database": "unavailable"
}
```

### Example

```bash
curl http://localhost:8080/api/health
```

## GET /rules

Returns the implemented rock-paper-scissors rules. Each map entry means the key beats the value.

### Request

No request body.

### Response 200

```json
{
  "items": ["rock", "paper", "scissors"],
  "rules": {
    "rock": "scissors",
    "scissors": "paper",
    "paper": "rock"
  }
}
```

### Example

```bash
curl http://localhost:8080/api/rules
```

## POST /sessions

Creates a new game session after the player chooses a starting item.

### Request Payload

```json
{
  "playerChoice": "rock"
}
```

Fields:

| Field | Type | Required | Validation |
| --- | --- | --- | --- |
| `playerChoice` | string | Yes | Must normalize to `rock`, `paper`, or `scissors`. |

### Response 201

```json
{
  "id": "4d93c354-d7c5-43cf-9be2-b7756117d4f2",
  "playerChoice": "rock",
  "status": "started",
  "winner": null,
  "initialRockCount": 10,
  "initialPaperCount": 10,
  "initialScissorsCount": 10,
  "finalRockCount": null,
  "finalPaperCount": null,
  "finalScissorsCount": null,
  "transformations": null,
  "durationMs": null,
  "createdAt": "2026-06-11T12:15:30.123456+03:00",
  "completedAt": null
}
```

### Example

```bash
curl -X POST http://localhost:8080/api/sessions \
  -H "Content-Type: application/json" \
  -d "{\"playerChoice\":\"rock\"}"
```

### Validation Errors

Invalid item:

```http
HTTP/1.1 400 Bad Request
```

```json
{
  "error": "Item must be one of: rock, paper, scissors."
}
```

Malformed JSON or missing required fields returns `400 Bad Request` with an error message from Ktor request deserialization.

## POST /sessions/{id}/complete

Completes a game session and stores the final winner, final item counts, number of transformations, duration, and completion timestamp.

### Path Parameters

| Parameter | Type | Required | Validation |
| --- | --- | --- | --- |
| `id` | string | Yes | Must be a valid UUID. |

### Request Payload

```json
{
  "winner": "paper",
  "finalRockCount": 0,
  "finalPaperCount": 30,
  "finalScissorsCount": 0,
  "transformations": 27,
  "durationMs": 12400
}
```

Fields:

| Field | Type | Required | Validation |
| --- | --- | --- | --- |
| `winner` | string | Yes | Must normalize to `rock`, `paper`, or `scissors`. |
| `finalRockCount` | integer | Yes | Must be `>= 0`. |
| `finalPaperCount` | integer | Yes | Must be `>= 0`. |
| `finalScissorsCount` | integer | Yes | Must be `>= 0`. |
| `transformations` | integer | Yes | Must be `>= 0`. |
| `durationMs` | integer | Yes | Must be `>= 0`. |

Additional completion rules:

- `finalRockCount + finalPaperCount + finalScissorsCount` must equal `30`.
- The declared `winner` must be the only remaining item.
- Therefore, the winner count must be `30`, and the other two final counts must be `0`.

### Response 200

```json
{
  "id": "4d93c354-d7c5-43cf-9be2-b7756117d4f2",
  "playerChoice": "rock",
  "status": "completed",
  "winner": "paper",
  "initialRockCount": 10,
  "initialPaperCount": 10,
  "initialScissorsCount": 10,
  "finalRockCount": 0,
  "finalPaperCount": 30,
  "finalScissorsCount": 0,
  "transformations": 27,
  "durationMs": 12400,
  "createdAt": "2026-06-11T12:15:30.123456+03:00",
  "completedAt": "2026-06-11T12:15:42.987654+03:00"
}
```

### Example

```bash
curl -X POST http://localhost:8080/api/sessions/4d93c354-d7c5-43cf-9be2-b7756117d4f2/complete \
  -H "Content-Type: application/json" \
  -d "{\"winner\":\"paper\",\"finalRockCount\":0,\"finalPaperCount\":30,\"finalScissorsCount\":0,\"transformations\":27,\"durationMs\":12400}"
```

### Validation Errors

Invalid winner:

```json
{
  "error": "Item must be one of: rock, paper, scissors."
}
```

Negative final count:

```json
{
  "error": "Final rock count cannot be negative."
}
```

Final counts do not add up to 30:

```json
{
  "error": "Final counts must add up to 30."
}
```

Winner is not the only remaining item:

```json
{
  "error": "The declared winner must be the only remaining item."
}
```

Negative transformations:

```json
{
  "error": "Transformations cannot be negative."
}
```

Negative duration:

```json
{
  "error": "Duration cannot be negative."
}
```

Invalid UUID:

```json
{
  "error": "Session id must be a valid UUID."
}
```

Missing session:

```http
HTTP/1.1 404 Not Found
```

```json
{
  "error": "Session not found."
}
```

## General Validation And Error Handling

- Unknown JSON fields are ignored by the server.
- Item fields are trimmed and lowercased before validation.
- Invalid request data raises `400 Bad Request` with `ErrorResponse`.
- Malformed JSON or missing required JSON fields raises `400 Bad Request`.
- Missing sessions return `404 Not Found`.
- Unexpected server failures return `500 Internal Server Error`.
- CORS is enabled for any host and allows `GET`, `POST`, and `OPTIONS`.

## Database Persistence

Sessions are stored in the `game_sessions` PostgreSQL table. The backend creates the table on startup if it does not exist.

Columns:

```sql
id UUID PRIMARY KEY,
player_choice VARCHAR(16) NOT NULL,
status VARCHAR(16) NOT NULL,
winner VARCHAR(16),
initial_rock_count INTEGER NOT NULL,
initial_paper_count INTEGER NOT NULL,
initial_scissors_count INTEGER NOT NULL,
final_rock_count INTEGER,
final_paper_count INTEGER,
final_scissors_count INTEGER,
transformations INTEGER,
duration_ms BIGINT,
created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
completed_at TIMESTAMPTZ
```
